# Análise F-Insight: Gratuito vs Premium

## Funcionalidades Gratuitas Disponíveis

### ✅ Disponível Gratuitamente:
1. **Radar de Ativos** - Completo com 20+ ativos BR/US/Cripto
2. **Painel Macroeconômico** - Acesso total
3. **Screener Profissional** - Filtros avançados, estratégias pré-definidas
4. **Gráficos de Preços** - Histórico de 3 meses
5. **Simulador de Estratégias** - 3 simulações/mês
6. **Assistente IA** - 5 perguntas/dia
7. **Alertas de Preço** - 3 alertas
8. **Watchlist** - 10 ativos

### ❌ Limitações do Gratuito:
- Sem exportação CSV/PDF
- Sem dashboard personalizado
- Sem notícias premium
- Sem análises exclusivas
- Com publicidade

## Vantagens Premium (R$ 29,90/mês ou R$ 358,80/ano)

### Pro:
- Simulações ilimitadas
- 100 perguntas IA/dia
- 50 alertas de preço
- 100 ativos na watchlist
- Exportação CSV/PDF
- Dashboard personalizado
- Sem publicidade
- Suporte prioritário

### Enterprise (R$ 199,90/mês):
- IA ilimitada
- Alertas ilimitados
- API de dados
- Suporte dedicado
- White label
- Múltiplos usuários

## Problemas Identificados

### 1. Inconsistência de Preços
- Página /premium: R$ 29,90/mês (Pro)
- Página /checkout: R$ 49/mês (Premium Mensal) e R$ 470/ano (Premium Anual)
- **PRECISA ALINHAR OS PREÇOS!**

### 2. Dados N/A na Homepage
- P/L, 52W Low, Volume, Market Cap mostram "N/A"
- Isso pode afastar usuários

### 3. Diferenciação Poderia Ser Mais Clara
- A tabela comparativa é boa, mas poderia ter mais destaque visual
- Falta mostrar exemplos práticos do que o Premium oferece

## Recomendações

1. **Alinhar preços** entre /premium e /checkout
2. **Corrigir dados N/A** - buscar dados completos das APIs
3. **Adicionar mais conteúdo gratuito atrativo** - artigos, tutoriais
4. **Mostrar preview de funcionalidades premium** - com blur/lock
5. **Adicionar contador de usuários/análises** - prova social
